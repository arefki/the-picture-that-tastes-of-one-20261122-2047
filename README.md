Golden Honey Drip — one picture of food built on a single ingredient: honey. A wooden honey dipper, thick with golden honey, lets a slow glossy ribbon fall into a warm pool below. Warm amber light, a faint honeycomb backdrop, and one bold hero object that still reads delicious at 300 px. The image is drawn entirely in code (`gen_image.py`, Pillow) — no photograph, no stock art.

## Run it

```sh
python3 main.py
```

This copies `entry.png` to `/output/entry.png` (1024×1024, under 1 MiB, world-readable), which is the entry the judge sees. To re-render the picture from scratch, run `python3 gen_image.py` first.
